Place the final full-game music file here as one of:

- `game-theme.mp3`
- `game-theme.m4a`
- `game-theme.ogg`
- `game-theme.wav`

The game loops this file on the main menu after the first click or key press, because browsers block autoplay before player interaction. Jumpscares use the configured hit windows in `src/audio/GameMusic.js` to land on louder moments in the track.

Chapter music lives in `music/`:

- Chapter 1: `chapter-1-heard.mp3` — “Heard” by Jeremy Chontow
- Chapter 2: `chapter-2-dont-turn-around.mp3` — “Don't Turn Around” by Steven Beddall
- Chapter 3: `chapter-3-it-comes-at-night.mp3` — “It Comes at Night” by Adam Dib
- Chapter 4: `chapter-4-sacred-earths.mp3` — “Sacred Earths” by Jeremy Chontow
- Chapter 5: `chapter-5-fog-choke.mp3` — “Fog Choke” by Rick Abbott

Keep the applicable license or purchase receipt for every track with the project records before publishing.
