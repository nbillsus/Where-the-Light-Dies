# Where the Light Dies

Browser game prototype for Where the Light Dies.

## Run locally

Install Node.js 20 or later, then run:

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal. Run `npm run build` to create the
production-ready `dist/` folder.

## Deployment

This is a Vite + Phaser browser game. Import the GitHub repository into Vercel;
Vercel detects the Vite build and deploys the generated static site. Every push
to the connected branch produces a new testable URL.

## Shared baseline

The repository includes an atmospheric title screen and a code-drawn lighthouse
graybox with basic movement and jumping. It is a temporary shared bootstrap, not
production art, lore, animation, or advanced mechanics.
