# Where the Light Dies

A browser-based atmospheric puzzle-platformer prototype. The current playable
build uses Vite and Phaser, so it runs directly in a web browser and can be
deployed to Vercel for classroom testing.

## Run locally

Install Node.js 20 or later, then run:

```bash
npm install
npm run dev
```

Open the local URL Vite prints in the terminal. Select `New Game` to begin in
the Watchful Hall, then run right into three scrolling parkour sections. Use
`A` / `D` or arrow keys to run, `Space` to jump, `R` to restart a parkour
section, and `Esc` to return to the menu. Falling respawns the character on
the most recent ledge. The shadow ability is not yet part of this preview.

## Build and deploy

Run `npm run build` to create a production build in `dist/`. Vercel builds this
project from source automatically when the repository is imported, so `dist/`
is intentionally not committed.

## Prototype scope

The title screen and opening room use supplied artwork. The three panoramic
parkour backgrounds are original editable SVG illustrations generated by
`node scripts/generate_parkour_art.mjs`; their ledges share coordinates with
the collision data in `src/levels/parkourData.js`. Collections will gain
entries when the team adds story content.
