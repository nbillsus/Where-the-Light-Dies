# Audio Asset Plan

This folder is for the project's ambience, music, sound effects, and radio voice-over files.

See `docs/AUDIO_DESIGN.md` for the audio direction, cue list, radio treatment, and naming convention.

## Folder Use

- `ambience/` - looping environmental beds such as rain, pier storm, caves, and cliff wind.
- `music/` - restrained musical loops and stingers.
- `sound_effects/` - one-shot gameplay and presentation cues.
- `radio/` - voice-over exports and processed radio transmissions.

Keep final exports as `.wav` during development unless the engine import pipeline requires another format.
